# Política de Segurança

## Versões suportadas

Somente a **versão mais recente** publicada em [Releases](https://github.com/brunocsilva41/DualAudioMirror/releases) recebe correções de segurança. Versões anteriores não são atualizadas — atualize antes de reportar um problema.

| Versão | Suporte |
| ------ | ------- |
| última release | ✅ sim |
| anteriores | ❌ não |

## Como reportar

Reporte vulnerabilidades **privadamente** usando os [GitHub Security Advisories](https://github.com/brunocsilva41/DualAudioMirror/security/advisories/new):

1. Abra o repositório no GitHub.
2. Vá na aba **Security**.
3. Clique em **Report a vulnerability**.
4. Descreva o problema: versão afetada, passos para reproduzir, impacto e, se possível, logs.

**Não abra uma issue pública** para vulnerabilidades.

## Tempo de resposta

- Confirmação do recebimento em até **7 dias úteis**.
- Avaliação de severidade e plano de correção em até **14 dias** após a confirmação.
- Correções de severidade crítica ou alta serão priorizadas e publicadas em nova release.

Você receberá atualizações pelo canal informado no relatório.

## O que não é vulnerabilidade

- Atraso (delay) no áudio durante o espelhamento.
- Incompatibilidade ou falha de driver de terceiros (ex.: VB-Cable, drivers de fabricante).
- Limitações de hardware ou do sistema operacional.
- Uso indevido do aplicativo fora do comportamento documentado.
